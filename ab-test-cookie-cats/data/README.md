# Data

Download `cookie_cats.csv` from the [Kaggle dataset page](https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats) and place it in this folder. The file is excluded from version control because the dataset page does not state explicit license terms.

Expected columns: `userid`, `version`, `sum_gamerounds`, `retention_1`, `retention_7`.
